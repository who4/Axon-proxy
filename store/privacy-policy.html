Axon Proxy — Privacy Policy

Effective Date: November 22, 2026 · Extension Version 2.0.0

Axon Proxy is a client-side Chrome extension that routes browser traffic through user-configured HTTP, HTTPS, or SOCKS5 proxy servers. We do not operate proxy servers, collect browsing history, track users, or transmit personal data to third-party analytics services.

1. Data Stored Locally on Your Device

All configuration data—including proxy server addresses, ports, optional authentication credentials, split-tunneling rules, and extension preferences—is stored exclusively inside Chrome's local extension storage (chrome.storage.local) or, when "Session-only credentials" is enabled, in volatile browser session memory (chrome.storage.session) that is cleared when Chrome closes.

2. Network Requests Made by the Extension

  • User-Configured Proxies: When connected, Chrome routes matching traffic directly through the proxy server you explicitly entered.
  • Optional Connection Diagnostics: When you connect or click "Test connection", Axon Proxy performs a lightweight check to https://api.ipify.org?format=json (to display your current external exit IP) and https://www.google.com/generate_204 (to measure round-trip latency). No user identifiers, credentials, or browsing history are sent.

3. How Chrome Permissions Are Used

  • proxy: Applies your selected proxy profile and generated PAC split-tunneling rules.
  • storage: Saves your proxy profiles, rules, and preferences locally on your device.
  • webRequest & webRequestAuthProvider: Supplies proxy authentication credentials exclusively to your configured proxy host and detects companion CDN hostnames loaded by the active tab for split-tunnel rules.
  • contextMenus: Adds right-click menu options to route or bypass the current site or link.
  • tabs: Reads the active tab's hostname so you can add one-click site rules and optionally reload tabs when rules change.
  • privacy: Applies Chrome's WebRTC IP handling policy when the WebRTC IP leak guard is enabled.
  • <all_urls>: Required by Chrome for proxy authentication callbacks and per-tab companion CDN detection across any site you choose to route.

4. Data Sharing & Selling

Axon Proxy does not collect, sell, rent, or transfer user data to any third parties. JSON backups exported by the user omit proxy usernames and passwords by default unless explicitly opted in.

5. Contact

If you have questions about this Privacy Policy, please contact the developer through the Chrome Web Store support listing for Axon Proxy.
