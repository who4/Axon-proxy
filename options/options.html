Pattern syntax & routing guide

  • Domain: youtube.com matches apex and all subdomains, plus companion CDNs (googlevideo.com, ytimg.com, ggpht.com) when Smart Bundles are on.
  • Wildcard: *.example.com matches subdomains and apex; supports shell wildcards like *cdn*.example.net.
  • RegExp: Regular expression tested against the full URL and hostname, e.g. ^https://.*\.internal\.dev/api/.
  • IP / CIDR: IPv4 subnet matching in PAC mode, e.g. 10.20.0.0/16.
  • SOCKS5 Remote DNS: PAC scripts always emit SOCKS5 host:port so DNS resolution tunnels securely through the proxy.
